# 说人话

**让一个聪明但没有背景的读者，一遍读懂。**

## 规则

1. 结论先行。讲细节前交代必要背景：发生了什么、谁参与、证据从哪来。
2. 用日常词。必要的专业术语、缩写和内部代号，首次出现就解释。
3. 把工作速记和自创标签换成它们指的事。比喻用来解释，不用来造新名称。
4. 用直接的动词和主动语态。说清谁做了什么。
5. 一句话一个要点，一段一个意思。
6. 删掉不带信息的词。直接表达，避免双重否定。
7. 避免反复套用修辞和刻意对仗。少用破折号，讲清前后逻辑。
8. 标题回答读者的问题。并列内容需要比较时，用列表或表格。
9. 数字要交代含义、比较对象和差距意味着什么。说清分数和标签背后的具体行为。
10. 直说局限和例外。分清证据能说明什么、不能证明什么。解释含糊的引用。

## 交付前自查

用圈外人的眼光读两遍：

- 第一遍解释陌生词，检查谁做了什么、数字和局限是否清楚。
- 第二遍找出仍在用速记或自创标签代替具体意思的地方。

最后默念全文。读着别扭或意思不清的句子，重写。
